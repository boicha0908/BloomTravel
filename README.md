# BLOOM TRAVEL

블룸웨딩의 카드·사이드바·반응형 구조를 참고해 만든 여행 플래너 웹사이트입니다. 원본 `블룸웨딩` 폴더는 수정하지 않았고, 이 폴더의 복사본만 수정했습니다.

## 포함된 기능

- 현재 여행 중심 대시보드와 여러 여행 전환
- 다구간 여행 정보, 도시·공항·출발일·귀국일 관리
- PC·태블릿의 달력 + 날짜별 타임라인, 모바일 여행 화면
- 일정 CRUD와 날짜 메모
- 항공권·숙소·교통·투어·보험·유심 예약 관리
- 비교 항목과 최종 선택 표시
- KRW 기준 예산, 여러 현지 통화, 사용자 지정 환율, 자동 환산
- 신랑·신부·공동 결제 구분과 50:50 기본 정산
- 준비 할 일 체크리스트 CRUD
- 엑셀 참고 목록 기반 준비물 체크리스트 66개
- 체크리스트 내부 `준비 할 일` / `준비물` 탭 전환
- 준비물 상태 순환: 빈칸 → 챙김 → 구매 예정 → 빈칸
- 준비물 카테고리·항목·담당자 수정, 추가, 삭제 (카테고리 분류 자체도 관리)
- 여행 중 오늘 일정, 연락처, 빠른 지출, 환율, 지도 연결
- 여행 다이어리, 방문 장소, 결산, 인쇄·PDF 저장
- 파트너 초대 UI와 Firebase 연결 안내 영역
- `manifest.json`과 `sw.js`를 통한 PWA 기본 구조

## 실행

`index.html`을 브라우저에서 열거나 로컬 서버로 실행할 수 있습니다. PWA 서비스 워커는 HTTPS 또는 localhost에서 활성화됩니다.

현재는 데모 모드로 동작하며 여행 데이터는 브라우저 로컬 저장을 사용합니다. 실시간 계정·공동 편집을 연결하려면 `firebase-config.js`에 Firebase 설정과 인증·Firestore 규칙을 추가하면 됩니다.
